# 🤖 СТРОГИЕ ПРАВИЛА И СТАНДАРТЫ ДЛЯ AI-АГЕНТОВ (AGENTS.MD)

Этот файл определяет постоянные обязательные правила для любого AI-ассистента и разработчика, работающего в этом репозитории.

---

## 1. СТРОГИЙ КОНТРОЛЬ ОБНОВЛЕНИЙ (CHANGE FILTER)

Перед внесением и коммитом любых изменений агент ОБЯЗАН проверить:
1. **Совместимость моделей AI:** Никогда не удалять и не заменять модели Gemini вслепую. Сверять со статусом Google AI Studio текущего года (в 2026 году модели 1.5 закрыты; актуальны 2.5 и 3.x).
2. **Нулевая потеря данных (Zero Data Loss):** Запрещены `deleteMany()` и жесткие удаления. Только `isArchived: true` (Soft-Delete) с окном восстановления 30 дней.
3. **Безопасность API:** Ни один защищенный маршрут не должен доверять заголовкам пользователя (`x-user-id`) — личность берется строго из расшифрованного JWT (`req.userId`).
4. **Мастер-PIN Администратора:** Мастер-пароль `22222222` служит 2-м фактором для авторизованных сотрудников, но НИКОГДА не заменяет JWT-токен для анонимных внешних запросов.
5. **Мессенджеры:**
   - **Telegram:** Только корпоративный аккаунт (GramJS / MTProto) с номером, аватаром и статусом «В сети». **НИКАКИХ БОТОВ!**
   - **WhatsApp:** Сессия Baileys обязана сохраняться в PostgreSQL (`MessengerSession`). При `SIGTERM`/`SIGINT` вызывается `waService.backupSessionToDatabase()`.

## 2. ОБЯЗАТЕЛЬНАЯ ТРИАДА ВЕРИФИКАЦИИ ПЕРЕД КОММИТОМ

Любая итерация кода завершается успешным прохождением всех трех этапов:

```bash
# Этап 1: Проверка типов бэкенда
cd server && npm run typecheck

# Этап 2: Сборка фронтенда
cd client && npm run build

# Этап 3: Насквозное тестирование роботом Playwright (должно быть 45/45 PASS)
cd .. && node test-crm-robot.js
```

Если хотя бы один тест упал — изменение бракуется и исправляется до 100% зеленого статуса.

## 3. ПОДКЛЮЧЕННЫЕ РАБОЧИЕ СКИЛЛЫ (.agents/skills/)

- `crm-security-guardian`: Защита маршрутов, timing-safe криптография, хранение токенов в `sessionStorage`.
- `crm-quality-gatekeeper`: Фильтрация полезных обновлений от деградации кода, гигиена репозитория.
- `crm-messenger-reliability`: 24/7 живучесть сессий WhatsApp и Telegram.
- `bitrix-ui-designer`: Корпоративный Bitrix24/amoCRM дизайн, капсула рабочего дня, Quick Dock.
- `crm-ai-copilot-engineer`: Внедрение ШІ-копилотов в сделки и чаты (1-click черновики, отработка возражений, скоринг сделок, оптимизация бесплатного каскада Gemini 2.5/3.x Flash).
- `crm-rag-knowledge-engine`: RAG-архитектура, семантический парсинг резюме/вакансий, векторные эмбеддинги и синаптический гибридный поиск.
- `crm-autonomous-agent-orchestrator`: Автономные агенты Digital Pipeline, авто-квалификация лидов, round-robin распределение на менеджеров, защита от спама и фоновые очереди.
