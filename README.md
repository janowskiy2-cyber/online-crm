# Online CRM Pro (amoCRM Edition)

Полнофункциональная CRM-система корпоративного уровня с дизайном и бизнес-логикой в стиле **amoCRM**, поддержкой омниканальных мессенджеров (**WhatsApp и Telegram по QR-коду**), матрицей из **20 пользователей и ролей (RBAC)**, интерактивной Kanban-доской, Digital Pipeline автоматизацией и расширенной аналитикой.

---

## 🌟 Ключевые возможности

### 1. Воронки продаж и Сделки (amoCRM Kanban & Deal Sheet)
- Drag-and-drop перемещение сделок между этапами с автоматическим пересчетом сумм и количества.
- Мультиворонки: B2B Корпоративные продажи, B2C Быстрые продажи, LTV и Сопровождение.
- Карточка сделки:
  - **Слева:** данные клиента, контакты, компания, теги, кастомные поля.
  - **По центру:** живой таймлайн истории событий, внутренних заметок и **прямой чат с клиентом в WhatsApp / Telegram**.
  - **Справа:** список задач с дедлайнами, статусами и напоминаниями.
  - **Индикатор:** статус «Без задачи» подсвечивается для предотвращения потери лидов (принцип amoCRM).

### 2. Омниканальный чат-центр (WhatsApp & Telegram по QR-коду)
- Подключение WhatsApp через сканирование QR-кода прямо в браузере.
- Подключение Telegram через QR-код / Bot API.
- Единый чат-центр (Unified Inbox) для ведения диалогов со всеми клиентами в одном окне.
- Автоматическое создание сделки и карточки контакта при первом входящем сообщении от нового клиента.
- Встроенный интерактивный симулятор входящих сообщений для быстрого тестирования автоворонок.

### 4. Автоматизация (Digital Pipeline)
- Триггеры: вход сделки на этап, создание сделки, входящее обращение.
- Автодействия: отправка шаблонного сообщения в WhatsApp/Telegram с подстановкой имени клиента и менеджера, постановка задачи, смена ответственного.

### 5. Аналитика и Дашборд KPI
- Воронка конверсии по этапам.
- Рейтинг менеджеров по полученной выручке.
- Анализ причин проигранных сделок.
- Метрики: общая выручка, средний чек, Win Rate (процент успешных сделок).

## 🚀 Запуск системы

### Быстрый запуск (Windows):
Дважды кликните по файлу `start.bat` в корне проекта или выполните:
```bash
npm run dev
```

### Адреса:
- **Frontend (Пользовательский интерфейс):** [http://localhost:3000](http://localhost:3000)
- **Backend API & WebSocket Server:** [http://localhost:5000](http://localhost:5000)
