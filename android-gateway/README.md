# 📱 OnlineCRM Android GSM Gateway & SIM Integration

Повнофункціональний автономний Android-шлюз для підключення реальних SIM-карт менеджерів до CRM-системи.

---

## ⚡ Можливості

1. **24/7 Автоматична фіксація дзвінків з SIM-карти:**
   - Фіксує вхідні, вихідні та пропущені дзвінки з точним хронометражем (секунди).
   - Миттєво знаходить клієнта в CRM та додає запис у таймлайн угоди (`DealNote`).
   - Якщо дзвонить новий номер — автоматично створює новий лід на першому етапі воронки.
   - Якщо дзвінок пропущений — ставить менеджеру гаряче завдання *"🔥 Передзвонити клієнту!"*.

2. **Перехоплення та вивантаження аудіозаписів розмов:**
   - Працює зі штатним системним диктофоном смартфона (Xiaomi/MIUI, Samsung OneUI, OnePlus, Tecno).
   - Автоматично знаходить аудіофайл розмови та завантажує його в CRM.
   - Плеєр для прослуховування з'являється прямо в картці угоди.

3. **Click-to-Call (Дзвінок в 1 клік з комп'ютера):**
   - Менеджер натискає кнопку виклику в веб-CRM на комп'ютері.
   - Смартфон автоматично починає набір номера через встановлену SIM-карту.

4. **0% витрати акумулятора в режимі очікування:**
   - Працює суто на подіях операційної системи Android (`BroadcastReceiver` + `WorkManager`).
   - Коли телефон не дзвонить — процес спить у пам'яті з нульовим навантаженням на процесор.

5. **Офлайн-буфер (Захист від втрати даних):**
   - Якщо розмова відбулася без інтернету (ліфт, паркінг, траса), дзвінок зберігається у внутрішній черзі та вивантажиться, щойно з'явиться 4G/Wi-Fi.

## 🚀 Встановлення та швидке налаштування

### Крок 1. Збірка або встановлення APK
- Зберіть проєкт у Android Studio або встановіть готовий файл `app-release.apk` на Android-смартфон менеджера.
- Надайте запитані дозволи: *Телефон*, *Журнал викликів*, *Сповіщення*, *Пам'ять*.

### Крок 2. З'єднання з CRM за 3 секунди
1. Відкрийте картку будь-якої угоди в веб-CRM на комп'ютері.
2. У верхній панелі дій натисніть кнопку **`📱 SIM-Шлюз`** (або у вікні виклику натисніть іконку QR).
3. Наведіть камеру смартфона на згенерований QR-код у додатку або введіть ID менеджера вручну.
4. Додаток покаже статус: **`🟢 GSM Шлюз активний (SIM 1)`**.

### Крок 3. Налаштування штатного запису дзвінків на смартфоні
- **На смартфонах Xiaomi / Redmi / POCO:**  
  Відкрийте додаток *«Телефон»* ➔ Налаштування (шестірня) ➔ *«Запис викликів»* ➔ Увімкніть **«Записувати виклики автоматично»**.
- **На смартфонах Samsung Galaxy:**  
  Відкрийте додаток *«Телефон»* ➔ 3 крапки вгорі ➔ Налаштування ➔ *«Запис викликів»* ➔ Увімкніть **«Автозапис викликів»**.
- **На смартфонах OnePlus / Oppo / Realme:**  
  Налаштування викликів ➔ *«Запис розмов»* ➔ **«Записувати всі номери»**.

## 🔒 Дозволи безпеки (Android Permissions)
- `READ_PHONE_STATE` — виявлення початку та закінчення телефонної розмови.
- `READ_CALL_LOG` — зчитування точної тривалості та номера виклику.
- `CALL_PHONE` — здійснення виклику за командою Click-to-Call.
- `FOREGROUND_SERVICE` — захист служби від вивантаження оптимізатором батареї.
