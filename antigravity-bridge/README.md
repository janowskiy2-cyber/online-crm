# 📱 Antigravity Mobile Telegram Remote Controller

Повноцінний мобільний пульт дистанційного керування активною сесією **Google Antigravity** через Telegram.

## 🚀 Можливості

- **🎙️ Голосове керування:** надиктуйте завдання у мікрофон Telegram — бот розпізнає мову (Gemini 2.5 Flash або автономний Google Web STT) та направить завдання агенту.
- **⚡ Hands-Free Режим (Авто-підтвердження):** вам більше не потрібно сидіти біля комп'ютера і тиснути кнопки в IDE — усі дії та плани затверджуються автоматично.
- **🔘 Мобільна клавіатура швидких дій:** закріплені кнопки під полем вводу в Telegram (`✅ Підтвердити дію`, `📊 Статус`, `🤖 Запустити тест robot`, `⚡ Авто-режим`).
- **📱 Інлайн-кнопки дій:** зручне підтвердження в 1 тап під кожним планом чи запитом.
- **📡 Двосторонній стрім:** бот у реальному часі транслює в Telegram поточний крок розробки («⚙️ Виконую: Editing file...») та надсилає фінальну відповідь.
- **🔒 Захист доступу:** бот працює виключно з вашим особистим `chat_id`.

## 🛠 Запуск

```bash
# Через батник в 1 клік
start-telegram-remote.bat

# Або напряму
node antigravity-bridge/telegram-bot.js
```
